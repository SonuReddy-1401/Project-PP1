# Pitch-Calibration-Clean / sn-calibration

This directory contains source modules adapted from SoccerNet calibration (`sn-calibration`).

## Components
- `src/camera.py`: Core `Camera` class providing 3D-to-2D projection math (`project_point`, `from_json_parameters`).
- `src/soccerpitch.py`: `SoccerPitch` 3D coordinate model of standard football pitch geometry.

## Note
Code files in this module are version-tracked; test output binaries and cached artifacts are excluded.
