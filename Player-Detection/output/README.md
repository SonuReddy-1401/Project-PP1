# Player-Detection / Output

This directory stores output MP4 videos and frame verification results generated by the full detection and filtering pipeline.

## Expected Content
- `clip1min_clean.mp4`: Clean output video containing valid on-pitch detections + pitch boundary polygon.
- `clip1min_debug.mp4`: Debug verification video showing clean detections + rejected overlay/off-pitch boxes.
- `robustness_test_10frames/`: 10-frame test visualizations and `summary.json`.

## Note
Generated `.mp4` video files and test frames are git-ignored to maintain a lightweight repository.
