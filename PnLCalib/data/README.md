# PnLCalib / Data

This directory stores broadcast video clips used for calibration and end-to-end player detection pipeline evaluation.

## Expected Content
- `broadcast_clip_1.mp4`: 2.5-minute match video clip (~7,500 frames).
- `broadcast_clip_2.mp4`: 1.0-minute match video clip (~1,600 frames).

## Setup Instructions
- Video files (`*.mp4`) are excluded from Git to prevent repository size bloat. Place required MP4 files here locally.
