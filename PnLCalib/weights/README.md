# PnLCalib / Weights

This directory holds pre-trained weights for keypoint and line segmentation network modules:

- `SV_kp`: HRNet keypoint detection weights.
- `SV_lines`: HRNet line segmentation weights.

## Note
Weight files (`SV_kp`, `SV_lines`) are excluded from Git version control. Ensure local weights are placed in this folder prior to running `export_pnlcalib_params.py` or video renderer scripts.
